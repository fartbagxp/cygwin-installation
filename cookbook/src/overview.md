# Overview

Worked examples for the network problems I keep running into, like a name that resolves differently depending on who you ask, or a certificate that verifies in the browser but not in curl.

Most of the tools run on Linux and inside [Cygwin](https://www.cygwin.com/), a Linux-like environment for Windows, so you can use the same commands on a locked-down Windows laptop. Each tool page lists where to get it on each platform.

The source is on [GitHub](https://github.com/fartbagxp/cygwin-installation).
