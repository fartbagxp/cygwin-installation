# Tools

Cygwin is a collection of open source tools providing Linux capabilities to Windows.

The following tools will provide insights into client and server behaviors when diagnosing and troubleshooting network issues.

Aside from tools within Cygwin, we often use other Linux networking tools to diagnose network problems.

## Open Source Tools

| Command Line Tool | Cygwin Package | Usage                                                          |
| ----------------- | -------------- | -------------------------------------------------------------- |
| [dig]             | bind-utils     | powerful DNS lookup tool, similar to nslookup                  |
| [netcat]          | nc, nc6        | swiss army knife for testing network connectivity              |
| [openssl]         | openssl        | library for testing SSL/TLS encryption algorithms              |
| [openssh]         | openssh        | a suite of utilities for the SSH protocol                      |
| [curl]            | curl           | command line tool for sending/receiving web requests           |
| [whois]           | whois          | a domain tool for looking up ownership of domains or IPs       |
| [ipcalc]          | ipcalc         | IP addressing calculator for subnet in CIDR notation           |
| [watch]           | procps         | create a cron job                                              |
| [trippy]          | N/A            | a network tool that uses a combination of ping and traceroute  |
| [mtr]             | N/A            | a re-implementation of traceroute for continuous monitoring    |
| [unfrl/dug]       | N/A            | DNS lookup tool on global DNS servers to check DNS propagation |
| [iperf3]          | N/A            | a highly efficient network traffic generator                   |
| [tcpdump]         | N/A            | swiss army knife for capturing network traffic                 |
